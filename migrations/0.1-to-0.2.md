Cross-platform executor (0.1 -> 0.2). No page shape changes; the QQ territory and
`wiki/qq/policy.md` stay as they are.

1. **Connector** — update `connectors/qq-cli` and reinstall it
   (`python -m pip install -e connectors/qq-cli`).
   The spool no longer imports `fcntl` directly: locking goes through
   `qqcli/locks.py` (POSIX `flock` / Windows `msvcrt`), and process control plus
   detaching go through `qqcli/platforms/` (POSIX `setsid` / Windows
   `DETACHED_PROCESS`). `qq-cli selftest` must pass (6 cases).
2. **Unattended executor** — the watcher is now `scripts/qq-agent-watch.py`
   (the `.sh` file is a shim). If the cron page exists, reinstall the executor
   after confirmation: `scripts/install-executor.sh` (systemd on Linux, launchd on
   macOS) or `windows/install-taskscheduler.ps1`. Every installer writes
   `~/.qq-cli/executor.json`; the init verify reads that marker.
3. **Cron page** — unchanged. Keep its `status` as-is: `active` only after a real
   reply test. The paused/default posture is not a 0.2 regression.
